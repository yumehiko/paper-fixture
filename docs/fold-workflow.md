# 資料から直線折りを含む組立を生成する設計

Blender担当は整形済み `.ai` と人が作れる寸法図・PDF・画像・自然文メモをagentへ渡す。agentが内部planを作り、決定論的CLIで生成・保存・別プロセス検証を行う。人にpath note、JSON、XYZ座標、行列の記入を依頼しない。

資料が十分なら一括承認を要求せずに続行する。不足または矛盾では「`BODY` の `FOLD_02` は印刷面側から見て山折りか谷折りか」「`FOLD_03` の可動側はどちらか」のように部材・折線を示して質問する。

内部planでは、各foldについて端点 `[0]` から `[1]` へ印刷面上をたどったときの可動側を `left` または `right` として確定する。生成器はすべてのfold半平面で平面セルを先に確定し、次に親子面ツリーの剛体変換を適用する。この順序により、二連鎖以降でも後段foldを既に移動した親の座標で切らない。端点順を反転する場合は `left`/`right` も反転し、同じ物理的な山谷になることを別プロセス検証する。

agentは寸法資料から内部的に `root_transform_mm`（foldした部材のroot face）と `flat_instances`（折らない部材）を同じ完成worldへ解決できる。いずれも剛体4×4行列で、平行移動だけmm単位にする。これは人が記入する入力ではない。資料に完成位置・向きがなければ、部材名と不足している配置条件を示して質問する。

前向き試験用の人向け資料は [完全なブリーフ](forward-test/operator-agent-brief.md) と [不足資料の例](forward-test/operator-agent-missing-brief.md) にある。これらは架空のdraft試験であり、原本AIはoperator-intake機能を結合した試験checkoutで別途用意する。無注記AIによる最終追試とは区別する。

初版は外周へ両端が接続する開いた直線、交差しない折線、面グラフが木の場合だけを扱う。曲線外周、穴、前面UV、厚みを保持する。折りは厚み中央面を軸にした剛体面であり、折り半径、厚み干渉、紙の変形、製造可能性は保証しない。曲線折り、閉ループ・交差fold、両面印刷、手編集の逆反映は対象外である。
