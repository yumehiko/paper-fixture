# 試作と検証の計画

## 1. 実案件を把握する

初期対象は折りのない複数部材の3段棚とトップボード。モデリングとテクスチャ反映に約3時間かかる。完成写真・.ai・配置寸法の仕様書を対応付け、部材とファイルの関係、実寸、印刷範囲を実データで確認する。

## 2. 入力の読み取りだけを検証する

Illustratorからの専用書き出しを第一候補として、実寸・曲線を含む切断境界・穴・印刷の位置を取り出せるかを確認する。成功条件は、生成した2D確認図を元データに重ねて判定できること。レイヤーなどの意味情報と共通座標が保持されるかを確認する。

この前に理想化サンプルを使い、明示入力から編集可能な `.ai` を再生成できることを確認する。小サンプルでは R20 のベジェ外周、φ24 の穴、左右・上下を判別できる片面図柄を検査する。複数部材サンプルでは左右側面、棚3枚、背面、トップボード、背面の2穴、部材IDの対応を検査する。生成・再オープン・構造検査・プレビューの証跡を残し、実案件データの検証結果とは分離する。

## 3. 平面モデルを検証する

長方形、穴のある形状、曲線を含む外周に対して、寸法・穴・厚み・印刷位置を確認する。初期は片面の向きが分かる非対称な図柄を使い、裏面と断面の紙色も確認する。両面の位置・反転の検証は両面印刷機能の追加時に行う。許容値は案件要件から決める。

## 4. 複数部材の配置と受け渡しを検証する

仕様書の配置値で側面板・棚板・背面板・トップボードを配置する。棚上面の床からの高さと厚みの関係を確認する。編集可能な.blendを開き、形状・印刷・配置が保たれることを確認する。斜俯瞰の納品想定アングルに加え、角度を動かして不自然な隙間や面の欠落を確認する。納品想定サイズは1920×1080pxとする。このサイズのレンダリングで曲線の滑らかさと印刷の鮮明さを確認し、曲線の分割精度とテクスチャ解像度を決める。出力画像サイズと元テクスチャの必要解像度は同一視せず、部材の画面内サイズとUV範囲を考慮する。具体的な確認用角度範囲・許容誤差は別途決める。

## 5. 実務への効果を測る

入力整理、配置寸法の入力、生成、確認・修正を含む総時間と修正回数を記録する。約3時間の従来作業を基準に、2時間以内を実用目標、1時間以内を理想目標とする。比較する作業範囲をそろえ、カメラ・照明・背景と納品レンダリングは別に記録する。

## 後続段階：折りと両面印刷

初期試作が成立してから両面印刷や折りの実装優先順位を決める。折りは一つの折り、連続する折り、閉じる形状の順に検証する。軸・角度・面の追従、厚み由来の干渉、UV維持を確認する。糊代・差し込み・しなりは必要範囲を確認してから追加する。

## 自動化への検証観点（追加案）

同じ組み立て指定を再実行して同じ状態を再現できるか、AIから必要な状態を取得し操作を呼び出せるかを確認する。人の介入回数と内容を記録し、幾何処理の不足、完成形の情報不足、外観判断の不足に分けて改善する。初期版の成立と、人力部分をほぼ排除する長期目標への進捗を別に評価する。

## 停止して設計を見直す条件

- 入力準備の負担が、削減できるBlender作業時間を上回る。
- よくある形状を面と折り線だけで十分に表せない。
- 厚みの簡略表現では納品に必要な見た目や寸法を満たせない。
- 新規生成を含む運用で、入力整理・配置指定の負担が大きく、実用目標の2時間以内に収まらない。形状改訂を新規生成で扱うこと自体は許容済み。
