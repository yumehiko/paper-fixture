# 架空の折り紙fixture 前向き試験用ブリーフ

これは paper-fixture の前向き試験専用に作った架空のデモであり、実案件の図面ではない。入力AIの注記レイヤーは draft のまま残っている。通常の抽出を使い、AIファイルを変更しないこと。

材料は厚さ3 mmの板紙で、印刷面は `PF_PRINT_FRONT` である。`BODY` は折らず、印刷面を上にした水平な基準板として置く。`BODY` の穴は開口のままにする。

`SIDE` の `FOLD_SIDE_TAB` を、印刷面から見て山折りにする。線をその始点から終点へたどったとき、可動側は右側である。完成内角は90度とする。`SIDE` の左側の面を固定側とし、折った右側が上へ立ち上がるようにする。

完成時、`SIDE` の固定側の下辺を `BODY` の右端へ接し、両者の印刷面の下側が同じ水平面になるように置く。`SIDE` は `BODY` の高さ方向中央にそろえる。ここで「右」「上」「中央」は、`BODY` の印刷面を上から見た向きを基準にする。

このブリーフとAIから結論できない寸法・向きがある場合は、推測せず部材名とfold IDを示して質問する。
